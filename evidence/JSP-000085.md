# JSP-000085 complete-proof evidence registration

## Catalog problem

**JSP-000085 / Erdős Problem 67 — Erdős discrepancy problem**

The awards catalog asks whether, for every assignment of signs ±1 to the
positive integers, the absolute sums over finite initial segments of some
homogeneous arithmetic progression are unbounded.

At the reviewed awards revision, JSP-000085 is recorded as `Solved` but
`Lean proof: No`.

## Located public formalization

A complete Lean development is publicly available in `plby/lean-proofs`.

- Repository: https://github.com/plby/lean-proofs
- Pinned commit: `8822f7ddef30fadbd92e1c6ab4ed897af356af5e`
- Source: `src/latest/ErdosProblems/Erdos67.lean`
- Terminal theorem: `erdos_67`
- Lean: `v4.33.0`
- Mathlib: `v4.33.0`

The terminal theorem states:

```lean
theorem erdos_67 (f : ℕ → ℤ) (hf : ∀ n, f n = -1 ∨ f n = 1)
    (C : ℝ) (hC : 0 < C) :
    ∃ d m : ℕ, 1 ≤ d ∧ 1 ≤ m ∧
      C < |((∑ k ∈ Finset.Icc 1 m, f (k * d) : ℤ) : ℝ)|
```

Thus every sign sequence has homogeneous progression partial sums exceeding
every positive real threshold in absolute value, which is the catalogued
unbounded-discrepancy statement.

The upstream Comparator manifest identifies `erdos_67` as the solution
theorem and permits only:

- `propext`
- `Classical.choice`
- `Quot.sound`
