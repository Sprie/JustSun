# JSP-000916 evidence registration

## Catalog problem

**JSP-000916 / Erdős Problem 1105**

The catalog asks for the anti-Ramsey behavior for the specified cycles and
paths: how many edge colors can be used while avoiding a rainbow copy.

At the time this evidence was prepared, the Justin Sun Prize catalog records
the problem as solved but still lists `Lean proof: No`, and an exact
JSP-000916 search found no upstream PR or issue.

## Located public formalization

The source explicitly states that both affirmative parts are proved:

1. the cycle asymptotic for every `k ≥ 3`;
2. the exact path formula for every `5 ≤ k ≤ n`.

The development also contains
`ErdosProblems/Erdos1105/UpstreamAudit.lean`, which documents why an older
diagonal-inclusive formal specification was incorrect and distinguishes it
from the corrected anti-Ramsey definition used by the completed proof.
