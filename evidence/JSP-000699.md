# JSP-000699 evidence registration

## Catalog problem

**JSP-000699 / Erdős Problem 843**

> Under every two-coloring of the squares, is every sufficiently large integer
> a sum of distinct squares of one color?

The current Justin Sun Prize catalog records the problem as solved but, at the
time this evidence was prepared, still lists `Lean proof: No`.

## Located public formalization

A complete Lean formalization is publicly available in `plby/lean-proofs`.

Pinned upstream repository:

- Repository: https://github.com/plby/lean-proofs
- Commit: `7d97d48c60396d8ca2ba67298a296749a8e0fe0b`
- Source: `src/latest/ErdosProblems/Erdos843.lean`
- Main theorem: `Erdos843.erdos_843`
- Lean: `v4.33.0`
- Mathlib: `v4.33.0`, manifest commit
  `db584cd6d46c92f209a44c0f1c829460d327499d`

The source states that the mathematical proof is the square specialization of
Conlon--Fox--Pham, *Subset sums, completeness and colorings*, Theorem 1.2.

Upstream attribution recorded in the source:

- Informal authors: David Conlon, Jacob Fox, Huy Tuan Pham
- Formal authors: Codex, GPT-5.6 Sol

This repository does **not** claim authorship of that formalization. The
contribution here is locating the omitted public proof, checking statement
correspondence, pinning the source, and independently reproducing the build and
axiom audit.

## Statement correspondence

The upstream theorem is:

```lean
theorem Erdos843.erdos_843 :
  ∀ colour : ℕ → Fin 2, ∃ N : ℕ, ∀ n : ℕ, N ≤ n →
    Erdos843.MonochromaticSquareSum colour n
```

and `MonochromaticSquareSum` requires a finite set of **distinct positive
square values**, all of one color, whose sum is exactly `n`.

This directly matches the JSP-000699 catalog question.
