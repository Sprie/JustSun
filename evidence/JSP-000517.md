# JSP-000517 evidence registration

## Catalog problem

**JSP-000517 / Erdős Problem 636**

The original problem asks whether every sufficiently large Ramsey graph on
`n` vertices has `Ω(n^(5/2))` induced subgraphs whose pairs
`(number of vertices, number of induced edges)` are pairwise distinct.

At the time this evidence was prepared, the Justin Sun Prize catalog records
the problem as solved but still lists `Lean proof: No`.

## Located public formalization

A complete Lean formalization is publicly available in `plby/lean-proofs`.

Pinned snapshot:

- Repository: https://github.com/plby/lean-proofs
- Commit: `8822f7ddef30fadbd92e1c6ab4ed897af356af5e`
- Source: `src/latest/ErdosProblems/Erdos636.lean`
- Main theorem: `Erdos636.erdos_636`
- Lean: `v4.33.0`
- Mathlib: `v4.33.0`

The pinned source defines an induced-subgraph profile as the pair consisting of
the selected vertex count and induced-edge count. Its terminal theorem states
that for every positive Ramsey constant `C`, all sufficiently large
`C`-Ramsey graphs contain a finite family of induced vertex sets with
pairwise-injective profiles and cardinality at least
`γ * n^2 * sqrt n`, i.e. `Ω(n^(5/2))`.

Upstream attribution recorded in the source:

- Mathematical authors: Matthew Kwan; Benny Sudakov
- Formal authors: Codex; GPT-5.6 Sol

This repository does **not** claim authorship of the mathematical result or the
Lean formalization. The contribution here is locating the omitted proof,
checking statement correspondence, pinning the source, and independently
reproducing its build and axiom audit.

## Statement correspondence

The terminal theorem is:

```lean
theorem Erdos636.erdos_636 (C : ℝ) (hC : 0 < C) :
    ∃ γ : ℝ, 0 < γ ∧ ∃ N : ℕ, ∀ n ≥ N,
      ∀ G : SimpleGraph (Fin n), Erdos88.HomogeneousFree C G →
        ∃ F : Finset (Finset (Fin n)),
          IsProfileInjectiveFamily G F ∧
            γ * (n : ℝ) ^ 2 * Real.sqrt n ≤ (F.card : ℝ)
```

`HomogeneousFree C G` is the no-clique/no-independent-set-at-logarithmic-scale
hypothesis used by the source, and `IsProfileInjectiveFamily` states exactly
that distinct induced vertex sets differ in their vertex count or induced edge
count.
