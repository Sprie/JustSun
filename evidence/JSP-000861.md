# JSP-000861 candidate evidence registration

## Catalog problem

**JSP-000861 — For a monic real-rooted polynomial, how long in total can the
real intervals on which its absolute value is less than one be?**

The current Justin Sun Prize catalog records this entry as:

- `Current status: Open`
- `Lean proof: No`

The wording matches the core of **Erdős Problem 1038**: optimize the Lebesgue
measure of the strict unit sublevel set
`{x : ℝ | |f(x)| < 1}` over monic real polynomials whose roots are all real
and lie in `[-1,1]`.

This candidate is therefore more than a stale Lean-proof flag: if the public
proof claim below survives reproduction and scope review, the catalog's
solution status may also need correction.

## Public complete-proof claim

A public complete formalization is available in two independently useful
locations.

### Original project

- Repository: https://github.com/ShouqiaoW/erdos
- Completion commit: `dc20752268ede5a3548e3d63ae74e45c3cfcf78c`
- Commit message: `Add complete Lean proof for Erdos Problem 1038`
- Original toolchain: Lean `v4.27.0`
- Root module: `1038/lean/Erdos1038.lean`
- Final audit: `1038/lean/Erdos1038/FinalAxiomAudit.lean`

The original project contains a theorem `Erdos1038.mainTheorem` whose
statement includes the exact infimum, exact supremum, nonattainment of the
infimum, and the equality case for the supremum. Its final audit explicitly
rejects `sorryAx`, native-evaluator trust axioms, and any axiom outside
`propext`, `Classical.choice`, and `Quot.sound`.

### Integrated current Lean snapshot

- Repository: https://github.com/plby/lean-proofs
- Commit: `8822f7ddef30fadbd92e1c6ab4ed897af356af5e`
- Source: `src/latest/ErdosProblems/Erdos1038.lean`
- Main public theorem: `Erdos1038.erdos_1038`
- Stronger theorem: `Erdos1038.mainTheorem`
- Lean: `v4.33.0`
- Mathlib: `v4.33.0`

The integrated terminal theorem states:

```lean
theorem erdos_1038 :
    infimumLength = ENNReal.ofReal L ∧
    supremumLength = ENNReal.ofReal (2 * Real.sqrt 2)
```

The definitions use exactly the Formal Conjectures admissibility conditions:
a nonconstant monic real polynomial, with all roots (counted with
multiplicity) real and contained in `[-1,1]`, and the measure of
`{x | |f.eval x| < 1}`.

## Statement correspondence

The public Formal Conjectures statement for Erdős 1038 asks for the infimum of
the same sublevel-set measure and separately records the known supremum. The
integrated proof gives exact values for both, so it covers the unresolved core
infimum question rather than merely a weaker bound or special case.

The Justin Sun Prize wording omits the normalization interval `[-1,1]` from
its short title, so the detail/source correspondence must be treated
carefully. The candidate should not be submitted upstream until the full
catalog/source interpretation is checked against the project's intended
problem source.
