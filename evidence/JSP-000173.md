# JSP-000173 complete-proof evidence registration

## Catalog problem

**JSP-000173 / Erdős Problem 179**

The awards catalog asks how many short arithmetic progressions in a finite
integer set force a longer arithmetic progression. Its cited resolution is the
Fox--Pohoata result.

At the reviewed awards revision, JSP-000173 is recorded as `Solved` but
`Lean proof: No`.

## Located public formalization

A complete Lean development is publicly available in `plby/lean-proofs`.

- Repository: https://github.com/plby/lean-proofs
- Pinned commit: `8822f7ddef30fadbd92e1c6ab4ed897af356af5e`
- Source: `src/latest/ErdosProblems/Erdos179.lean`
- Terminal theorem: `Erdos179.erdos_179`
- Lean: `v4.33.0`
- Mathlib: `v4.33.0`

The source states and proves both Fox--Pohoata conclusions:

1. the threshold for three-term progressions to force a four-term progression
   is little-o of the trivial quadratic scale:
   `F 3 n 4 = o(n^2)`;
2. for every fixed `k > 3`, the logarithmic exponent of `F 3 n k`
   tends to two:
   `log (F 3 n k) / log n -> 2`.

The terminal theorem is:

```lean
theorem erdos_179 :
    (fun n : ℕ ↦ (F 3 n 4 : ℝ)) =o[Filter.atTop]
        (fun n : ℕ ↦ (n : ℝ) ^ 2) ∧
      ∀ k : ℕ, 3 < k →
        Filter.Tendsto
          (fun n : ℕ ↦ Real.log (F 3 n k) / Real.log n)
          Filter.atTop (nhds 2)
```

The upstream Comparator manifest names `Erdos179.erdos_179` as the solution
theorem and permits only:

- `propext`
- `Classical.choice`
- `Quot.sound`
