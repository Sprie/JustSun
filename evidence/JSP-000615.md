# JSP-000615 existing-proof evidence registration

## Catalog problem

**JSP-000615 / Erdős Problem 747 (Shamir's problem)**

The catalog asks for the density/edge threshold at which a random
three-uniform hypergraph acquires a perfect matching. At the reviewed awards
revision the entry is `Solved` but records `Lean proof: No`.

## Located public formalization

A complete public Lean development is available in `plby/lean-proofs`.

- Repository: https://github.com/plby/lean-proofs
- Pinned commit: `8822f7ddef30fadbd92e1c6ab4ed897af356af5e`
- Source: `src/latest/ErdosProblems/Erdos747.lean`
- Main theorem: `Erdos747.erdos_747`
- Median-threshold asymptotic: `Erdos747.erdos747_asymptotic`
- Lean: `v4.33.0`
- Mathlib: `v4.33.0`

The source states the full two-sided fixed-edge probability resolution:
for the uniform `M`-edge 3-uniform hypergraph on `3n` labelled vertices,
the perfect-matching threshold is asymptotic to `n log n`.  It also proves
the equivalent asymptotic law for the median critical edge count.

The repository's ComparatorChallenges metadata selects
`Erdos747.erdos_747` as the terminal theorem for Erdős Problem 747.
