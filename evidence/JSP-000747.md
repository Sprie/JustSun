# JSP-000747 evidence registration

## Catalog problem

**JSP-000747 / Erdős Problem 896**

> Under the stated restrictions, how many uniquely represented products can
> two integer sets have?

At the time this evidence was prepared, the Justin Sun Prize catalog records
the problem as solved but still lists `Lean proof: No`.

## Located public formalization

A complete Lean formalization is publicly available in `plby/lean-proofs`.

Pinned source snapshot used for reproduction:

- Repository: https://github.com/plby/lean-proofs
- Commit: `7d97d48c60396d8ca2ba67298a296749a8e0fe0b`
- Source: `src/latest/ErdosProblems/Erdos896.lean`
- Main theorem: `Erdos896.erdos_896`
- Lean: `v4.33.0`
- Mathlib: `v4.33.0`

The source defines `maxF N` as the maximum number of products with exactly one
ordered representation from two subsets of `{1,...,N}`, and proves

```lean
(fun N : ℕ ↦ (maxF N : ℝ)) =Θ[atTop] scale896
```

where `scale896` is the Erdős--Tenenbaum--Ford scale
`N² / ((log N)^δ (log log N)^(3/2))`.

Upstream attribution recorded in the source:

- Informal authors: Przemek Chojecki; GPT-5.5 Pro
- Formal authors: Codex; GPT-5.6 Sol

This repository does **not** claim authorship of the mathematical result or the
formalization. The contribution here is locating the omitted proof, checking
the catalog/theorem correspondence, pinning the source, and independently
reproducing the build and axiom audit.
