# JSP-000590 existing-proof evidence registration

## Catalog problem

**JSP-000590 / Erdős Problem 722**

The catalog asks whether, for fixed `k > r ≥ 1`, every sufficiently large
order satisfying the standard divisibility conditions admits a design in which
every `r`-subset lies in exactly one `k`-block.

At the reviewed awards revision the entry is `Solved` but records
`Lean proof: No`.

## Located public formalization

A complete public Lean development is available in `plby/lean-proofs`.

- Repository: https://github.com/plby/lean-proofs
- Pinned commit: `8822f7ddef30fadbd92e1c6ab4ed897af356af5e`
- Source: `src/latest/ErdosProblems/Erdos722.lean`
- Main theorem: `Erdos722.erdos_722`
- Lean: `v4.33.0`
- Mathlib: `v4.33.0`

The theorem states:

```lean
theorem erdos_722 :
    ∀ k r : ℕ, 0 < r → r < k →
      ∃ n₀ : ℕ, ∀ n : ℕ, n₀ ≤ n → IsAdmissible n k r →
        ∃ blocks : Finset (Finset (Fin n)), IsSteinerSystem n k r blocks
```

This is exactly the eventual-existence statement encoded by the catalog:
the necessary divisibility conditions are sufficient for all sufficiently
large admissible orders.

The repository's ComparatorChallenges metadata selects
`Erdos722.erdos_722` as the terminal theorem for Erdős Problem 722.
