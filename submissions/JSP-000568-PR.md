## Problem and proposed change

Problem ID: **JSP-000568** / Erdős Problem 697.

The current catalog records the problem as **Solved** but lists
`Lean proof: No`.

This correction registers an already-public complete Lean proof of Hall's sharp
phase transition, preserves upstream attribution, and marks the entry
**Pending verification** rather than asserting eligibility.

For the density `δ(m, α)` of integers divisible by some
`d ≡ 1 (mod m)` with `1 < d < exp(m^α)`, the pinned source proves the full
phase transition with critical exponent `β = 1 / log 2`:

- `1 < β`;
- for every `α < β`, `δ(m, α) → 0` as `m → ∞`;
- for every `α > β`, `δ(m, α) → 1` as `m → ∞`.

The mathematical result is credited by the pinned source to **Richard R. Hall**.
The pinned source names **Codex** and **GPT-5.6 Sol** as formal authors.
The submitter **Sprie** claims neither mathematical nor formalization
authorship; this PR contributes source discovery, statement correspondence,
immutable pinning and reproducible verification evidence.

theorem erdos_697 :
    1 < 1 / Real.log 2 ∧
      (∀ α : ℝ, α < 1 / Real.log 2 →
        Tendsto (fun m : ℕ => δ m α) atTop (𝓝 0)) ∧
      (∀ α : ℝ, 1 / Real.log 2 < α →
        Tendsto (fun m : ℕ => δ m α) atTop (𝓝 1))

matching the prose problem statement and Hall's theorem.
