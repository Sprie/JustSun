## Problem and proposed change

Problem ID: **JSP-000586** / Erdős Problem 718.

The current catalog records the problem as **Solved** but lists
`Lean proof: No`.

This correction registers an already-public complete Lean proof of the
quadratic complete-subdivision forcing bound and marks the entry
**Pending verification** rather than asserting eligibility.

The pinned terminal theorem proves that there exists a universal constant
`C > 0` such that every nonempty finite graph with at least
`C r² |V|` edges contains a subdivision of `K_r`.  The development
takes `C = 5`, equivalently giving an average-degree threshold of order
`r²`, matching the catalog problem.
