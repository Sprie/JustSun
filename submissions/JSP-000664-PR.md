## Problem and proposed change

Problem ID: **JSP-000664** / Erdős Problem 807.

The current catalog records the problem as **Solved** but lists
`Lean proof: No`.

This correction registers an already-public complete Lean proof resolving the
random-graph bipartite-decomposition conjecture negatively and marks the entry
**Pending verification** rather than asserting eligibility.

The pinned source formalizes the conjecture that, asymptotically almost surely
in `G(n,1/2)`, the bipartition number equals `n - α(G)`, and proves this
false. It also formalizes the stronger Alon--Bohman--Huang improvement: for an
explicit positive constant `c`, the bipartition number is asymptotically
almost surely at most `n - (1+c) α(G)`, together with a logarithmic saving.
